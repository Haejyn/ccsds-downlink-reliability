# 요구사항 명세 — SpaceLink (CCSDS TM 다운링크 수신 처리)

> 지상국 영상수신처리 시스템의 첫 단계 — 위성이 보낸 전송 프레임을 검증하고 가상 채널별로 Space Packet 을 재조립한다.
> 기준 표준: CCSDS 132.0-B (TM Space Data Link Protocol), CCSDS 133.0-B (Space Packet Protocol).
> 시험 코드는 `[Trait("Requirement", "REQ-…")]` 로 요구사항을 가리킨다.

## 핵심 계약

> **손상됐을 가능성이 있는 패킷은 절대 내보내지 않는다. 손상과 무관한 패킷은 모두 복구한다.**
> 영상·텔레메트리 처리 체인의 뒷단은 수신기가 넘긴 패킷을 믿고 처리하므로, "조용한 손상"은 유실보다 나쁘다.

## 기능 요구사항

| ID | 요구사항 | 판정 기준 |
|---|---|---|
| REQ-CRC-01 | FECF 는 CRC-16/CCITT-FALSE 로 계산한다 | 표준 검사값 "123456789" → 0x29B1, 비트 단위 기준 구현과 무작위 3,000 버퍼 일치 |
| REQ-FRM-01 | 전송 프레임 주 헤더를 표준 비트 배치대로 부호화·복호화한다 | 수작업 비트 배치 벡터 일치, 무작위 4,000 프레임 왕복 (OCF 유·무) |
| REQ-FRM-02 | 채널 비트 오류가 있는 프레임은 받아들이지 않는다 | 1115 바이트 프레임 **단일 비트 오류 8,920 가지 전수**, 2·3·5 비트 무작위 각 20,000, 16 비트 이하 버스트 20,000 — 통과 0 |
| REQ-FRM-03 | 구조가 잘못된 프레임은 CRC 가 맞아도 이유와 함께 거부한다 | 길이·버전·동기 플래그·세그먼트 길이·제1 헤더 포인터 범위·OCF 플래그 |
| REQ-PKT-01 | Space Packet 주 헤더를 표준 비트 배치대로 부호화·복호화한다 | 수작업 벡터 일치, 무작위 5,000 패킷 왕복 |
| REQ-PKT-02 | 필드 범위 밖·형식 오류 패킷은 거부한다 | APID ≤ 2047, 순서 카운트 ≤ 16383, 데이터 1~65536 바이트, 버전 0, 길이 필드 일치 |
| REQ-EXT-01 | 여러 프레임에 걸친 패킷·프레임 경계에서 쪼개진 헤더·유휴 프레임이 있어도 패킷을 순서대로 정확히 재조립한다 | 3,000 패킷(최대 706 바이트) · 프레임 카운트 3회 이상 순환 — 출력 = 입력, 이벤트 0 |
| REQ-EXT-02 | 가상 채널이 섞여 들어와도 채널별로 독립 재조립한다 | 두 채널 무작위 교차 — 채널별 출력 = 입력 |
| REQ-EXT-03 | 프레임 유실·비트 오류·순서 뒤바뀜에서 **손상 패킷 0**, 영향받지 않은 패킷은 전부 복구 | 출력 = 손상 프레임과 한 바이트도 겹치지 않는 원본 패킷 전부 (유실률 2·5·20 %) |
| REQ-EXT-04 | 중복 수신 프레임은 무시한다 | 출력 = 입력, 중복 이벤트 수 = 주입 수 |
| REQ-EXT-05 | APID 별 패킷 순서 카운트 건너뜀을 보고한다 | 주입한 건너뜀 1건 = 이벤트 1건 |
| REQ-EXT-06 | **프레임 카운트로 감지되지 않는 유실(256 장 단위 연속 유실)에서도 손상 패킷을 내보내지 않는다** | 256·512 장 연속 유실 × 40 시도 × 5 시드 — 원본에 없는 패킷 0 |
| REQ-EXT-07 | 어떤 입력 바이트열에도 예외로 중단되지 않는다 | 무작위 바이트 50,000 · CRC 가 맞는 무작위 프레임 50,000 |
| REQ-EXT-08 | 실시간 수신 처리량 | **단일 스레드 벤치마크**(`benchmarks/SpaceLink.Benchmarks`, 128 바이트 프레임)에서 1,000,000 프레임/초 이상. 시험 안의 처리량 단언은 병렬 시험 부하 속 **회귀 하한 5,000 프레임/초**일 뿐, 처리량 수치로 인용하지 않는다 |
| REQ-EXT-09 | 패킷 버전 번호가 0 이 아니면 동기를 잃은 것으로 보고, 다음 제1 헤더 포인터까지 그 가상 채널의 조립 데이터를 버린다 | 잘못된 버전 헤더가 든 프레임 다음에 이어지는 데이터에서 패킷을 만들지 않는다 — `InvalidPacketHeader` 이벤트 1건, 출력 0 |

## 품질 요구사항

| ID | 기준 |
|---|---|
| QR-01 | 컴파일러·.NET 분석기(권장 규칙) 경고 0 — `TreatWarningsAsErrors` |
| QR-02 | 라인 커버리지 ≥ 90 %, 분기 ≥ 85 % (coverlet) |
| QR-03 | 뮤테이션 점수 ≥ 80 % (Stryker.NET) — 도구가 대상 프레임워크를 지원할 때 |
| QR-04 | Linux·Windows 에서 같은 결과 (GitHub Actions 매트릭스) |
